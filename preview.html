Dovetail Layout Preview

Layout only: tail positions, widths and depths, checked against the bit. No toolpaths yet. Drag the round handles, or click any number to type it.

Tails board on top, the mating board it fits into below, to the same scale.

Round handles drag: tail tips set length, the lower corners of a tail set its width, the edges of the boards and the dashed lines set sizes. Each tail has its own sideways grip, which makes the spacing irregular. Hold Shift to skip snapping. The pill on the tails board slides the whole pattern sideways without changing any size, and the mating board follows; type -1/4 for left. Typing: 5/8, 1 1/2, 0.75, add mm or in to override the unit, or 7/8t for a fraction of the mating board thickness. Both boards are taken as the same width, as in a box corner.
